# Neue Regrade Font Installation

## Place Your Font Files Here

This folder is ready for your Neue Regrade font files.

### What to Add:

Place your Neue Regrade font files (WOFF2 or WOFF format) here:

**If you have separate style files:**
- NeueRegrade-Regular.woff2
- NeueRegrade-Italic.woff2
- NeueRegrade-Bold.woff2
- NeueRegrade-BoldItalic.woff2

**If you have variable fonts:**
- NeueRegrade-Variable.woff2 (or NeueRegrade-VF.woff2)

### Converting TTF/OTF to WOFF2:

If your fonts are in TTF or OTF format, convert them online:
- https://cloudconvert.com/ttf-to-woff2
- https://www.fontsquirrel.com/tools/webfont-generator

### After Adding Fonts:

The CSS is already configured to load them automatically!
Check styles.css - @font-face rules are at the top.

### Fallback:

If fonts aren't loaded, the site uses system fonts as backup.
