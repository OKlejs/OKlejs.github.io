GIT STRUCTURE
=============
When you push to GitHub, it will look like this:

yourusername/portfolio (repository)
├── main (branch)
│   ├── index.html
│   ├── styles.css
│   ├── script.js
│   ├── .gitignore
│   ├── README.md
│   └── assets/
│       ├── profile.jpg
│       ├── architecture/
│       └── photography/
│
└── gh-pages (GitHub Pages - auto-created)
    └── Deployed site


DEPLOYMENT WORKFLOW
===================

Local Machine:
  ↓
  Edit files
  ↓
  Test in browser
  ↓
  git add .
  git commit
  git push
  ↓
GitHub Repository:
  ↓
  Processes files
  ↓
GitHub Pages:
  ↓
  Builds site
  ↓
Live Website:
  https://username.github.io/portfolio/


WORKFLOW EXAMPLE
================

Day 1: Setup
------------
1. Download all files
2. Open in code editor
3. Update index.html with your info
4. Update script.js with your projects
5. Test locally (open index.html)

Day 2: Images
-------------
1. Collect and optimize images
2. Place in assets/ folders
3. Verify filenames match script.js
4. Test locally again

Day 3: Deploy
-------------
1. Create GitHub account
2. Create new repository
3. Upload all files
4. Enable GitHub Pages
5. Wait 3-5 minutes
6. Visit your live site!

Day 4: Polish
-------------
1. Test on multiple devices
2. Set up contact form
3. Fix any issues
4. Share your portfolio!


TIPS
====

✅ DO:
- Keep image files under 500KB
- Test locally before pushing
- Make one change at a time
- Commit frequently
- Use descriptive commit messages

❌ DON'T:
- Edit files directly on GitHub (edit locally)
- Upload huge uncompressed images
- Delete important files
- Push untested changes
- Forget to optimize images


NEED HELP?
